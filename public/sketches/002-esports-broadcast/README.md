# Variante 2: Esports Broadcast

## Stance
HUD de transmissão competitiva (LoL/Dota/Valorant spectate): painéis flat, bordas de 1-2px, contraste brutal, zero ornamento. Legibilidade acima de tudo.

## Escolhas-chave
- **Layout:** grid 3 colunas (1fr auto 1fr) com borda inferior colorida por time; deck flat sem moldura PNG
- **Tipografia:** Rajdhani em tudo; timer 26px centro absoluto
- **Cor:** azul #3f6ec4 / vermelho #c4433f saturados contra carvão #0b0d12; dourado SÓ no indicador de ult pronto
- **Interação:** slots quadrados com letra no canto, CD radial, contagem de respawn direto no retrato (chip numérico)

## Trade-offs
- **Forte:** leitura instantânea em 1080p ou stream comprimida; escala para esports/spectator
- **FracO:** abandona os PNGs do atlas Storm (precisa emenda ao contrato §1); menos "Naruto", mais "genérico pro"

## Melhor para
Gameplay competitivo, clareza sob stress, streamers/espectadores.
