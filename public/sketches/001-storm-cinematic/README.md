# Variante 1: Storm Cinematográfico

## Stance
Leaning 100% no acervo autêntico do APK (`docs/UI_SKIN_CONTRACT.md`-compliant): painéis 9-slice reais, algarismos desenhados, emblemas e ícones do jogo original — mas com disciplina tipográfica que o HUD atual não tem.

## Escolhas-chave
- **Layout:** top bar 48px assimétrica (time→score→centro VS→score→time), deck inferior com minimapa emoldurado pelo `panel_silver` real
- **Tipografia:** UMA família de UI (Barlow Condensed) + Noto Sans JP apenas para selos japoneses (木ノ葉/敵, 奥義) + Cinzel removido do HUD (só marca)
- **Cor:** ouro do jogo como acento único; azul/konoha vs vermelho apenas em tags e dots
- **Interação:** slots compactos 54px com key badge dourada, CD radial, hover com brilho; botões de ação viram letras (CAM/TAB/?/✕) — zero emoji

## Trade-offs
- **Forte:** autenticidade máxima — parece o jogo de luta Storm de verdade; contrato de skin intacto
- **FracO:** densidade visual maior; painéis 9-slice exigem slice calibration perfeito para não distorcer

## Melhor para
Fãs de Naruto/Ultra Ninja Storm que querem "o jogo original em formato MOBA" — fator nostalgia máximo.
